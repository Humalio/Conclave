# Conclave server

Fastify and Node.js host the MCP endpoint, console API, bridge endpoints, and domain services. SQLite migrations run at startup. The console is served from [public](public/).

See the [quickstart](../docs/getting-started.md) for setup and tests, the [architecture](../docs/architecture.md) for code ownership, and the [MCP reference](../docs/mcp.md) for tool discovery and client setup.
