# Agent Hub

Agent Hub is a self-hosted service for AI sessions that need to communicate, work in teams, and use a shared Obsidian vault. Sessions connect over MCP; operators govern access and inspect activity in a web console. A desktop bridge moves larger files within approved local folders.

Start with the [developer guide](docs/README.md), [system specification](docs/specification.md), or [quickstart](docs/getting-started.md). The [server](server/), [bridge](bridge/), and [evaluation harness](eval/README.md) live in this repository.

Try [Things We Kept for Each Other](demo/README.md), an Obsidian vault and live agent hearing about a human and a robot who claim the same memory.
